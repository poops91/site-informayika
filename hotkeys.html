Гарячі клавіші

Комбінації клавіш допомагають швидше виконувати типові дії на комп’ютері.

Корисні комбінації

Ctrl + C

Копіювати вибраний текст або файл.

Ctrl + V

Вставити скопійований або вирізаний елемент.

Ctrl + X

Вирізати вибраний текст або файл.

Ctrl + Z

Скасувати останню дію.

Ctrl + S

Зберегти документ або файл у програмі.

Ctrl + A

Вибрати весь текст або всі елементи у вікні.

Alt + Tab

Перемикатися між відкритими вікнами.

Win + E

Відкрити Провідник файлів у Windows.
